# Open City — браузерный 3D открытый мир

Смесь GTA San Andreas и GTA V на **Three.js**, без бандлера: обычные HTML/JS/CSS
и ES-модули. Three.js грузится с CDN через `importmap`.

Что уже есть: город 1000×1000 с улицами и зданиями, игрок (ходьба, бег, прыжок, драка),
оружие (пистолет, обрез, автомат: прицел с зумом, отдача, перезарядка, урон по зонам тела),
рэгдолл при смерти, звук выстрелов, машины (езда, угон), прохожие, три банды с территориями,
розыск и полиция (пешая и на машинах, стреляет с 3 звёзд), трафик, здоровье/смерть/арест,
миникарта, управление с клавиатуры и с телефона.
Пока **нет**: заданий банды, денег и магазинов, инвентаря с весом, прокачки, сюжета.

## Запуск

ES-модули не работают через `file://`, нужен любой статический сервер:

```bash
# из корня репозитория
python3 -m http.server 8000 --directory src
# или
npx serve src
```

Откройте `http://localhost:8000/`. Нужен интернет: Three.js (0.160.0) берётся с `cdn.jsdelivr.net`.

### На телефоне
- Любая ссылка на `src/index.html` через веб-сервер, например GitHub Pages
  (Settings → Pages → ветка, игра будет по адресу `.../src/`) или
  `https://raw.githack.com/<владелец>/<репозиторий>/<ветка>/src/index.html`.
- Сборка в один файл: `node tools/build-single-file.mjs` → `dist/open-city.html`
  (все модули внутри, three.js с CDN; флаг `--body` — без обёртки `<html>`, для хостингов,
  которые добавляют её сами). Бандлер нужен только для этой сборки, для разработки — нет.

## Управление

| Клавиатура/мышь | Пешком | В машине |
|---|---|---|
| W A S D | движение относительно камеры | газ / тормоз-задний ход / руль |
| Мышь | камера (pointer lock), колесо — зум | то же; без мыши ~1 с камера сама встаёт за машину |
| Shift | бег | — |
| Space | прыжок | ручник (занос) |
| F / левая кнопка мыши | удар кулаком или выстрел (автомат — удерживать) | — |
| ПКМ / C (удерживать) | прицел: камера за плечом, зум, меньше разброс | — |
| R | перезарядка (при `infiniteAmmo: false`; по умолчанию патроны бесконечные) | — |
| Q, 1–4 | смена оружия: кулаки, пистолет, обрез, автомат | — |
| E | сесть в машину / угнать с водителем | выйти |
| E у двери банка / магазина | ограбить | — |
| T | позвать банду (отряд) / отпустить | то же — бойцы садятся к вам в машину |
| J | меню банды: задания, репутация, районы | то же |
| M | звук вкл/выкл | |
| H / Esc | подсказка / пауза | |

Клавиши привязаны по `e.code`, поэтому работают и на русской раскладке.
Если захват мыши недоступен, камеру можно вращать, зажав кнопку мыши.

**Телефон** (включается сам на сенсорных экранах, `ui/touch.js`): джойстик слева
(до упора — бег; в машине — газ/тормоз/руль), свайп справа — камера, кнопки
УДАР/ОГОНЬ (без прицела — автонаведение на ближайшего противника), ПРИЦЕЛ (переключатель),
смена оружия, ПРЫЖОК/РУЧНИК, СЕСТЬ/УГНАТЬ/ВЫЙТИ/ГРАБИТЬ, справа вверху — пауза, БАНДА и ЗАДАНИЯ. На телефоне автоматически включается
облегчённая графика (`CONFIG.graphics.mobile`) и меньше машин на дорогах.

## Как это устроено

### Соглашения
- **1 юнит = 1 метр**, ось **Y — вверх**. Мир — квадрат от −500 до +500 по X и Z.
- Направление объекта — угол `heading`; «вперёд» = `(sin h, 0, cos h)`, «вправо» = `(-cos h, 0, sin h)`,
  т.е. `heading = 0` смотрит в +Z. `mesh.rotation.y = heading`.
- Модели строятся «лицом» в +Z; левая сторона — +X (у машины там дверь водителя).
- Движение правостороннее. «Север» на миникарте — −Z.
- Город генерируется детерминированно из `CONFIG.seed`.

### Игровой цикл (`main.js → Game._frame`)
1. Ввод камеры, клавиши E (машина / банк) и T (отряд) — раз за кадр.
2. Симуляция фиксированными подшагами ~1/60 с (`Game._simulate`):
   `player → vehicles → npcs → gangs → squad → wanted → traffic → resolveInteractions`.
   Затем раз за кадр: предметы на земле, ограбления, войны за районы, задания, эффекты, автосохранение.
   Пока открыто меню банды (`game.menuOpen`), симуляция стоит.
3. Камера, солнце (тень следует за игроком), рендер, HUD, миникарта, сенсорные кнопки.
4. Смерть/арест: `game.onPlayerDown('wasted' | 'busted')` → надпись → через `respawnDelay`
   возрождение у больницы или участка (`CONFIG.player.hospital` / `policeStation`), розыск сброшен.

Все системы получают `game` и обращаются к соседям через него:
`game.world`, `game.player`, `game.vehicles`, `game.npcs`, `game.gangs`, `game.squad`, `game.heists`,
`game.progress`, `game.turf`, `game.missions`,
`game.wanted`, `game.traffic`, `game.wallet`, `game.roads`, `game.input`, `game.cameraRig`, `game.hud`, `game.events`.
Машины добавляются/убираются через `game.addVehicle(v)` / `game.removeVehicle(v)`.
Для отладки объект доступен в консоли как `window.game`.

### Мир (`world.js`)
- Улицы по линиям `world.roadLines` (10 по каждой оси, шаг 100 м, ширина 14 м).
- Между улицами — 9×9 кварталов (`world.blocks`, индекс `j * 9 + i`): бордюр → тротуар 5 м → участок (`lot`).
  Тип: `'buildings'` или `'park'` (`CONFIG.world.parks`). `blockAt(x, z)` — квартал в точке.
- Здания склеены в меши по 3×3 квартала; фонари и деревья — `InstancedMesh`.
- Препятствия — AABB в `world.colliders` (`type: building | lamp | tree | barrier`).
- API: `getGroundHeight`, `resolveCircle`, `isCircleFree`, `isPointInsideBuilding`,
  `waypoints` (узел = угол квартала, `links`, `block`), `nearestWaypoint`, `waypointsNear`.

### Люди (`humanoid.js`, `npc.js`, `player.js`)
- Модель из примитивов, суставы — вложенные `THREE.Group`. Детали одного сустава склеены в один
  меш с vertex colors (12 мешей на человека, один материал). Внешний вид — `look`:
  `skin, hair, shirt, pants, shoes, hat, bandana, scale`.
- `animate(dt, { speed, airborne, pose, fall, sitHeight, guard, attack, attackSide })`,
  позы: `normal | sit | stumble | down`, плюс стойка и удар.
- NPC: роль `civilian | gang | police`, здоровье/урон — `CONFIG.npc.roles`.
  Состояния `NPC_STATE`: `walk, idle, fight, stumble, down, getup, dead, drive`.
  Общие методы бойца (есть и у игрока): `takeDamage(amount, attacker, dirX, dirZ, kind)`,
  `isDead`, `isDown`. У NPC ещё `aggro(target)`, `dropTarget()`, `stumble`, `knockDown`,
  `enterVehicle(v)` / `exitVehicle()`, `say(text)`.
- NPCManager держит ~`CONFIG.npc.count` прохожих вокруг игрока (дальних пересоздаёт рядом),
  прячет модели дальше `visibleDistance` и не обновляет дальше `freezeDistance`.

### Бой (`combat.js`)
`Melee` — удар длиной 0.38 с, урон в момент выпада тому, кто стоит перед бойцом.
Третий удар подряд сбивает с ног. Урон от машины — в `interactions.js` (зависит от скорости).

### Оружие (`weapons.js`, `ballistics.js`, `CONFIG.weapons`)
- Параметры ствола: `damage` (за пулю), `pellets` (дробинок у обреза), `fireRate`, `auto`, `magazine`,
  `spread` + `bloom` (разброс растёт от стрельбы и движения), `recoil` (подброс камеры),
  `range`, `reload`, `impulse` (толчок тела), `twoHanded` (поза).
- `Gun` — состояние ствола (магазин, запас, перезарядка), `Arsenal` — оружие игрока.
  `CONFIG.player.infiniteAmmo` (включено) — у игрока бесконечные патроны, перезарядка не нужна (HUD: ∞).
  После смерти/ареста остаётся только `CONFIG.player.startWeapons`.
- Выстрел игрока: луч из камеры находит точку под перекрестьем, пуля летит в неё из груди
  (так стены у ствола не мешают). На телефоне без прицела — автонаведение (`findAssistTarget`).
- `fireShot()` пускает лучи (с разбросом) и берёт ближайшее попадание: мир (сетка коллизий, обход ячеек
  по лучу), машины (коробка в их осях), люди (капсулы между суставами из `humanoid.getJoints()`).
  Урон × `CONFIG.hitZones`: голова ×3 (по игроку максимум ×1.5), корпус ×1, конечности ×0.65.
- NPC стреляют, если цель в прямой видимости (`lineOfSight`) и ближе 75% дальности; реакция,
  разброс, темп и урон по игроку — `CONFIG.npc.gun*`. Выстрелы пугают прохожих (`panicRadius`)
  и повышают розыск, если рядом свидетели или полиция.
- Оружие на земле (`pickups.js`): точки `CONFIG.pickups.spots` + выпавшее из убитых NPC.

### Рэгдолл (`ragdoll.js`)
При смерти `humanoid.getJoints()` даёт 15 точек, из них строится `Ragdoll`: Verlet-интеграция,
кости постоянной длины, распорки корпуса, минимальные расстояния (локти/колени не складываются
насквозь), колени гнутся только вперёд. Точки сталкиваются с землёй, стенами и машинами (машина
сносит тело своей скоростью). Пули добавляют импульс (`ragdoll.impulse`). Неподвижное тело «засыпает».
`humanoid.applyRagdoll()` поворачивает суставы модели по точкам; `resetPose()` — обратно в анимацию.

### Банды (`gangs.js`, `CONFIG.gangs`)
Три банды; территория — список кварталов, видна на миникарте, при входе всплывает название.
Члены бродят по тротуарам своей территории (`allowedNodes`) и тусуются на углах.
Враждебные нападают на игрока, если он пешком на их территории ближе `aggroRadius`,
и на любого, кто ударил своего (зовут друзей в `helpRadius`). Банда игрока (`friendly: true`)
не отвечает на его удары, вступается за него и помогает в его драках с бандитами.
Погибших пополняют раз в `respawnDelay` секунд вне поля зрения.

### Розыск и полиция (`wanted.js`, `CONFIG.wanted`)
`heat` растёт от событий (`character:damaged`, `character:killed`, `vehicle:carjack`), звёзды = `floor(heat)`.
Полиции немного: `footCopsPerStar` пеших на звезду (не больше `maxFootCops`), подкрепление раз
в `spawnInterval` с. 1–2 звезды — догоняют и задерживают (держат `bustTime` → «АРЕСТОВАН»),
вытаскивают из стоящей машины. С 3 звёзд (`carsFrom`) — стреляют, патрульные машины с мигалками
гонятся (ИИ в режиме `pursuit`) и высаживают полицейских рядом с игроком.
Без преступлений и без полиции рядом звёзды гаснут по одной (`calmTime` + `calmPerStar` на звезду).

### Машины и трафик (`vehicle.js`, `traffic.js`)
- `vehicle.controls = { throttle, steer, handbrake }` каждый шаг заполняет водитель:
  игрок (клавиатура/джойстик) или `vehicle.ai` (AIDriver). Физика одна для всех.
- AIDriver едет по правой полосе от перекрёстка к перекрёстку (цель — точка на полосе в нескольких
  метрах впереди), на перекрёстке выбирает направление, тормозит перед машинами/людьми, сигналит,
  сдаёт назад, если застрял. `mode = 'pursuit'` — маршрут к игроку, вблизи — прямо на него.
- TrafficManager держит `CONFIG.traffic.count` машин в 70–170 м от игрока, дальние убирает.
  Угнанные и брошенные машины перестают быть трафиком; далёкие брошенные удаляются
  (кроме стартовых — у них `persistent = true`).

### Отряд банды (`squad.js`, `CONFIG.squad`)
T (кнопка БАНДА) зовёт до `max` бойцов своей банды: ближние (`recruitRadius`) присоединяются сразу,
остальные прибегают из-за угла. Ещё раз T — отпустить (уходят на свою территорию).
- Бойцы идут по бокам от игрока (`FOLLOW` в `npc.js`), догоняют бегом, застрявших/отставших
  отряд подтягивает к игроку вне поля зрения.
- Кого бьют: цель игрока (в кого он целится или кого бьёт — прохожие тоже) → тех, кто напал на
  игрока/бойца → полицию при розыске → чужие банды рядом. Не отходят от игрока дальше `leash`.
- Игрок сел в машину — бойцы бегут к своим дверям и садятся пассажирами (`vehicle.passengers`),
  из окон стреляют по целям отряда (`driveByRange`). Игрок вышел — выходят и они.
- Пули игрока и отряда друг в друга не попадают (`isAlly` в `ballistics.js`).

### Банки, магазины и ограбления (`world.js` → `_buildBanks`/`_buildStores`, `heists.js`)
Банк (`CONFIG.banks`) — здание с колоннадой, магазин 24/7 (`CONFIG.stores`) — павильон с витриной;
оба стоят фасадом к улице в квартале `block`, сторона `side` (место в квартале резервируется,
обычные дома там не строятся). У двери — метка "$" (банк зелёная, магазин оранжевая; на миникарте
тоже). Подойти пешком, E (ГРАБИТЬ): сигнализация, сразу `alarmStars` звезды (не гаснут, пока идёт
ограбление), из банка выбегают охранники (`guard`: стреляют, а не задерживают), в магазине продавец
просит не стрелять. Продержаться `duration` секунд не дальше `leaveRadius` от входа — деньги
`reward`, место закрыто на `cooldown`. Ушёл, сел в машину, погиб — ограбление сорвано.

### Репутация (`progress.js`, `CONFIG.reputation`)
Очки (`points`): убитый конкурент, ограбление, задание, захваченный/отбитый район. Уровни
(`levels`, значения наследуются) дают отряду бойцов (`squad`), здоровье (`health`), оружие
(`weapons`) и точность (`spread`); отряд подхватывает бонусы сразу (`rep:level`).

### Войны за районы (`turf.js`, `CONFIG.turf`)
Убить `killsToStart` бандитов чужой банды на их территории (игрок пешком в том же квартале) —
«ВОЙНА ЗА РАЙОН»: волны `waves`, нельзя уходить дальше `leaveRadius`. Победа — квартал переходит
банде игрока (`gangs.transferBlock`), деньги и репутация. Раз в `attackEvery` секунд конкуренты
нападают на захваченный квартал: `defendTime` секунд, чтобы перебить их, иначе квартал потерян.
Банда без кварталов считается разгромленной. Захваченное сохраняется.

### Задания (`missions.js`, `ui/gang-menu.js`, `CONFIG.missions`)
Меню банды (J / ЗАДАНИЯ) ставит игру на паузу. Одновременно одно задание: цель показана столбом
света и жёлтой меткой на миникарте, текст — вверху экрана (`hud.setObjective`).
- **Угон тачки** — золотой спорткар у бордюра → в гараж банды (`garage`).
- **Зачистка точки** — `enemies` бандитов на углу чужого района (красные на миникарте).
- **Ограбление магазина** — ограбить указанный магазин (обычное ограбление + бонус).
- **Доставка груза** — фургон к метке за `time` секунд, за вами гонятся машины конкурентов.
Новое задание: класс с `start()`/`update(dt)`/`cleanup(success)`, свойства `target` и `objective`,
запись в `MISSIONS` и награда в `CONFIG.missions`.

### Деньги (`economy.js`, `CONFIG.economy`)
Из убитых выпадают пачки денег (`drops` по ролям), подлетают к игроку (`magnetRadius`); главный
заработок — банки, магазины и задания. Деньги, репутация и захваченные районы сохраняются в
`localStorage` (сброс: `game.save.reset()` и перезагрузка).

### События (`events.js`)
`vehicle:enter/exit/crash/carjack`, `npc:pushed`, `npc:knockdown`, `character:damaged`,
`character:killed`, `combat:hit`, `weapon:fired`, `wanted:changed`, `zone:changed`, `player:down`, `player:respawn`,
`money:changed`, `heist:start/success/fail`, `rep:level`, `turf:war/attack/changed`, `game:pause/resume`. Подписка: `game.events.on('character:killed', ({ target, attacker, kind }) => …)`.

## Как добавлять новое

**Параметры.** Почти всё — в `config.js`.

**Новая банда или территория.** Запись в `CONFIG.gangs.list`: `id`, `name`, `color`, `blocks: [[i, j], …]`,
`friendly` для банды игрока. Всё остальное (миникарта, спавн, агрессия) подхватится само.

**Новая машина на карте.** `CONFIG.vehicle.spawns` (`x, z, heading, color`, `police: true` — патрульная).
Позиции на дороге: оси улиц — `−450 + 100·i`, полосы — ±1.75 и ±5.25 м от оси.

**Новый тип транспорта.** Вынесите размеры/физику в конфиг-профиль и передавайте в `Vehicle`,
модель стройте отдельной функцией вместо `sharedAssets()`. Остальные системы используют только
`position, heading, velocity, speed, circles, radius, controls, driver, ai, seatAnchor, seatHipHeight,
distanceToPoint(), findExitPosition(), localToWorld2D()`.

**Новый тип NPC.** Роль в `CONFIG.npc.roles`, функция внешности как `gangLook`/`policeLook`,
реакции — в `NPC._onAttacked` / `NPC.stumble`, поведение — новое состояние в `NPC.update`.
Для сложного поведения удобно унаследоваться от `NPC`.

**Новое оружие.** Запись в `CONFIG.weapons` + модель в `weapons.js` (`models()`: ствол вдоль +Z,
рукоять вниз, начало — в ладони, `muzzle` — точка дула) + место в `WEAPON_ORDER`.
Дать NPC — вероятность в `CONFIG.npc.roles[role].weapons`; положить в город — `CONFIG.pickups.spots`.

**Новая метка на миникарте.** `Minimap._drawBlips()`; `this.toScreen(x, z)` — мир → пиксели.

**Новая клавиша / сенсорная кнопка.** Действие в `BINDINGS` (`input.js`); кнопка — `<button data-action="...">`
внутри `#touch` в `index.html` (стиль в `style.css`). Читать: `input.isDown(a)` / `input.wasPressed(a)`.

**Новый элемент HUD.** Разметка — `index.html` в `#hud`, стили — `style.css`, логика — `ui/hud.js`
(удобно подписываться на события).

## Известные ограничения

- Коллизии 2D (в плоскости XZ): на крыши машин и зданий запрыгнуть нельзя.
- Физика машины аркадная, без подвески и опрокидывания.
- NPC не ищут путь в обход препятствий — ходят по графу тротуаров и выталкиваются коллизиями;
  ИИ-машины при застревании просто сдают назад.
- На слабых телефонах много людей в кадре могут снижать FPS (счётчик — в левом верхнем углу).
- NPC и бойцы отряда в перестрелке стоят на месте, укрытия пока не ищут.
- Пули не пробивают препятствия; стрелять из машины нельзя.
