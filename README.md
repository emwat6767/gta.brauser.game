# Open City — браузерный 3D открытый мир (фундамент)

Смесь GTA San Andreas и GTA V на **Three.js**, без бандлера: обычные HTML/JS/CSS
и ES-модули. Three.js грузится с CDN через `importmap`.

Сейчас сделана только база: город, игрок, машины, пешеходы, миникарта.
Банд, полиции, розыска, сюжета, стрельбы и инвентаря пока **нет** — это следующие сессии
(см. «Что делать дальше»).

## Запуск

ES-модули не работают через `file://`, нужен любой статический сервер:

```bash
# из корня репозитория
python3 -m http.server 8000 --directory src
# или
npx serve src
```

Откройте `http://localhost:8000/`. Нужен интернет: Three.js (0.160.0) берётся с `cdn.jsdelivr.net`.

Для GitHub Pages: публикуйте ветку целиком, игра будет по адресу `.../src/`.

## Управление

| Клавиша | Пешком | В машине |
|---|---|---|
| W A S D | движение относительно камеры | газ / тормоз-задний ход / руль |
| Мышь | камера (pointer lock), колесо — зум | то же; через ~1 с без мыши камера сама встаёт за машину |
| Shift | бег | — |
| Space | прыжок | ручник (занос) |
| E (или F) | сесть в ближайшую машину | выйти |
| H | показать/скрыть подсказку | |
| Esc | пауза | |

Клавиши привязаны по `e.code`, поэтому работают и на русской раскладке.
Если захват мыши недоступен, камеру можно вращать, зажав кнопку мыши.

## Как это устроено

### Соглашения
- **1 юнит = 1 метр**, ось **Y — вверх**. Мир — квадрат от −500 до +500 по X и Z.
- Направление объекта хранится как угол `heading`; «вперёд» = `(sin h, 0, cos h)`,
  т.е. `heading = 0` смотрит в +Z. `mesh.rotation.y = heading`.
- Модели строятся «лицом» в +Z; левая сторона — +X (у машины там дверь водителя).
- «Север» на миникарте — −Z.
- Город генерируется детерминированно из `CONFIG.seed` — поменяйте сид, получите другой город.

### Игровой цикл (`main.js → Game._frame`)
1. Ввод камеры (мышь) и клавиша E (сесть/выйти) — раз за кадр.
2. Симуляция фиксированными подшагами ~1/60 с (`Game._simulate`):
   `player.update → vehicles[].update → npcs.update → resolveInteractions`.
3. Камера, солнце (тень следует за игроком), рендер, HUD, миникарта.

Все системы получают `game` и обращаются к соседям через него:
`game.world`, `game.player`, `game.vehicles`, `game.npcs.list`, `game.input`,
`game.cameraRig`, `game.hud`, `game.events`. Для отладки объект доступен в консоли как `window.game`.

### Мир (`world.js`)
- Улицы идут по линиям `world.roadLines` (10 по каждой оси, шаг 100 м, ширина 14 м) через весь мир.
- Между улицами — 9×9 кварталов (`world.blocks`): бордюр 15 см → кольцо тротуара 5 м → участок (`lot`).
  Тип квартала: `'buildings'` или `'park'` (список парков — `CONFIG.world.parks`).
- Здания: участок рекурсивно режется на парцеллы (`_subdivide`), на каждой — коробка;
  к центру города здания выше. Стены — одна текстура окон, цвет — через vertex colors.
  Геометрия склеивается в меши по 3×3 квартала → мало draw calls.
- Фонари и деревья — `InstancedMesh`.
- Каждое препятствие — AABB в `world.colliders` (`{minX,maxX,minZ,maxZ,height,type}`,
  type: `building | lamp | tree | barrier`).
- API для других систем:
  - `getGroundHeight(x, z)` — 0 на дороге, высота бордюра на тротуаре/в квартале;
  - `resolveCircle(pos, r, out)` — вытолкнуть круг из препятствий и границ мира (нормаль в `out`);
  - `isCircleFree(x, z, r)`, `isPointInsideBuilding(x, y, z)`;
  - `waypoints` — граф тротуаров (узел = угол квартала, `links` — соседи, включая переходы-зебры),
    `nearestWaypoint(x, z)`, `waypointsNear(x, z, r)`.

### Персонажи (`humanoid.js`)
Человек собран из примитивов: капсула-торс, сфера-голова, цилиндры-конечности. Суставы —
вложенные `THREE.Group` (бедро → колено → голеностоп, плечо → локоть), скелета нет.
`humanoid.animate(dt, { speed, airborne, pose, fall, sitHeight })` рисует цикл шага/бега
по скорости и позы: `'normal' | 'sit' | 'stumble' | 'down'`. Геометрии общие, материалы кэшируются по цвету.

### Машины (`vehicle.js`)
- Модель: выдавленный профиль кузова, стеклянный салон (виден водитель), арки, бамперы, фары,
  стоп-сигналы (загораются при торможении), 4 колеса (передние поворачиваются, все вращаются).
  Геометрия общая для всех машин, у каждой свой материал краски.
- Физика: скорость раскладывается на продольную и боковую; газ/тормоз/задний ход меняют продольную,
  боковая гасится сцеплением (`grip`, на ручнике — `gripHandbrake` → занос). Поворот —
  «велосипедная» модель: `yawRate = v / wheelBase * tan(steer)`, руль слабее на скорости.
- Коллизии: машина = 3 круга вдоль оси. Отскок от стен с закруткой, обмен импульсом между машинами.
- Без водителя машина плавно тормозит (`parkedDecel`).

### Пешеходы (`npc.js`)
Конечный автомат: `walk → idle → walk…`, реакции `stumble` (толчок шагом — пошатнулся и убегает)
и `down → getup` (сбит бегом или машиной — отлетает, лежит 2–3 с, встаёт, убегает).
Маршрут — случайное блуждание по графу тротуаров без разворотов назад;
в панике выбирает узел дальше от игрока.

### События (`events.js`)
Уже отправляются: `vehicle:enter`, `vehicle:exit`, `vehicle:crash`, `npc:pushed`, `npc:knockdown`,
`game:pause`, `game:resume`. Подписка: `game.events.on('npc:knockdown', ({ npc, by, cause }) => …)`.

## Как добавлять новое

**Параметры.** Почти всё настраивается в `config.js`: число NPC, скорости, физика машины, парки, камера.

**Новая машина на карте.** Добавьте запись в `CONFIG.vehicle.spawns` (`x, z, heading, color`).
Позиции на дороге: оси улиц — `−450 + 100·i`, полосы — ±1.75 и ±5.25 м от оси.

**Новый тип транспорта** (грузовик, мотоцикл). Вынесите размеры/параметры физики в конфиг-профиль,
передавайте его в конструктор `Vehicle`, а модель стройте отдельной функцией вместо `sharedAssets()`.
Остальным системам (камера, миникарта, посадка) важно только: `position`, `heading`, `velocity`, `speed`,
`circles`/`radius`, `seatAnchor`, `seatHipHeight`, `driver`, `distanceToPoint()`, `findExitPosition()`.

**Новое поведение NPC.** Добавьте состояние в `NPC_STATE` и ветку в `switch` в `NPC.update`.
Для другого типа персонажей (полицейский, бандит) удобнее унаследоваться от `NPC`
и переопределить `update`/`_chooseNext`, а внешний вид задать через параметры `Humanoid`.

**Новый тип здания/квартала.** Добавьте тип в `_layoutBlocks` (например, `'plaza'`) и его постройку
в `_buildBlocks`/`_buildBuildings`. Не забудьте коллайдер в `world.colliders` и отрисовку на миникарте
(`Minimap._renderStatic`).

**Новая метка на миникарте.** Допишите цикл в `Minimap._drawBlips()`; `this.toScreen(x, z)` переводит
мировые координаты в пиксели миникарты.

**Новая клавиша.** Добавьте действие в `BINDINGS` (`input.js`), проверяйте `input.isDown('action')`
или `input.wasPressed('action')`.

**Новый элемент HUD.** Разметка — в `index.html` внутри `#hud`, стили — `style.css`, логика — `ui/hud.js`.

## Что делать дальше (план следующих сессий)

- **Полиция и звёзды розыска** — новый модуль `wanted.js`: подписаться на `npc:knockdown`
  (особенно `cause: 'vehicle'`) и `vehicle:crash`, копить уровень розыска, HUD со звёздами.
- **Банды** — наследник `NPC` с территорией (набор кварталов `world.blocks`) и враждебностью.
- **Стрельба и инвентарь** — `weapons.js` / `inventory.js`; луч от камеры, попадание по кругам NPC,
  реакция через существующий `knockDown`.
- **Трафик** — те же `Vehicle`, но с ИИ-водителем, который едет по полосам улиц (оси `world.roadLines`)
  и поворачивает на перекрёстках; ввод водителя нужно абстрагировать (сейчас `update` читает `game.input`).
- Урон машин, угон с водителем внутри, день/ночь (фонари уже есть), звук, сохранения.

## Известные ограничения

- Коллизии 2D (в плоскости XZ): на крыши машин и зданий запрыгнуть нельзя.
- Физика машины аркадная, без подвески и опрокидывания.
- NPC не обходят препятствия — они просто идут по тротуару и выталкиваются коллизиями.
