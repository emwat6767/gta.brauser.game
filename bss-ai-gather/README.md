# BSS AI Gather — бот для Bee Swarm Simulator на телефоне

Работает на **Android** через бесплатное приложение **AutoJs6**.
На iPhone так нельзя: iOS не даёт приложениям видеть экран и нажимать за тебя (только с джейлбрейком).

## Что делает бот
- **Видит токены**: ищет их цвета на экране и отсеивает всё, что не похоже на круглую монетку (полосы, заливки цветов, интерфейс).
- **Выбирает лучший токен**: важность ÷ расстояние, держится за текущую цель и не мечется. Токены, добавленные кнопкой «+ВАЖНЫЙ», ценятся в 3 раза выше.
- **Бежит джойстиком под любым углом** и добегает, когда токен подобран.
- **Косит поле змейкой** и тапает инструментом, когда токенов нет.
- **Помнит центр поля** и не убегает за токенами дальше «поводка».
- **Не тупит у стен**: если 2,5 секунды не приближается к цели — прыгает и на время бросает это направление.
- **Сам сдаёт мёд**: рюкзак полный → ресет → Make Honey → ждёт → бежит обратно на поле (если задан маршрут).

## Установка
1. Скачай AutoJs6 с GitHub: https://github.com/SuperMonster003/AutoJs6/releases (файл `.apk`) и установи.
2. Скинь на телефон файл `bss_ai_gather.js` и открой его в AutoJs6 (или создай новый скрипт и вставь текст).
3. Дай AutoJs6 разрешения: **Спец. возможности (Accessibility)** и **Поверх других окон**.
4. Нажми ▶ на скрипте. Когда спросят про **запись экрана** — разреши.
5. Переключись в Roblox → Bee Swarm Simulator. Поверх игры появится панель (её можно таскать за верхнюю строку).

## Настройка (один раз)
**Камера:** отдали её и смотри на поле сверху. Во время работы камеру не крути.

**1. Точки** — нажми **ТОЧКИ**. Появится красный прицел: тащи его так, чтобы **пустой центр** прицела был на нужном месте, и снова жми **ТОЧКИ**. Порядок:

| Точка | Куда ставить | Обязательно? |
|---|---|---|
| ПЕРСОНАЖ | центр своего персонажа | да |
| ДЖОЙСТИК | где обычно ставишь палец для ходьбы слева | да |
| ТАП | пустое место справа, куда тапаешь, чтобы махать инструментом | желательно |
| ПРЫЖОК | кнопка прыжка | желательно |
| РЮКЗАК | правый конец полоски пыльцы, **когда рюкзак не полный** | для сдачи мёда |
| МЕНЮ | значок Roblox слева сверху | для сдачи мёда |
| RESET CHARACTER | открой меню и наведи на пункт | для сдачи мёда |
| RESET | кнопка подтверждения | для сдачи мёда |
| MAKE HONEY | встань у улья и наведи на кнопку | для сдачи мёда |

Ненужную точку пропускай кнопкой **ПРОПУСК**.

**2. Цвета токенов** — включи **ПРИЦЕЛ**, наведи центр прицела на токен и нажми **+ТОКЕН** (или **+ВАЖНЫЙ** для тех, что нужнее всего). Квадратик в углу панели покажет, какой цвет взят. Сделай так для каждого вида токенов. **СБРОС** — удалить все цвета.

**3. Старт** — встань в центр поля и жми **СТАРТ**. Бот запоминает это место как центр поля. **СТОП** — пауза.

## Маршрут обратно на поле
Без маршрута бот после сдачи мёда остановится и попросит довести персонажа до поля вручную.
Чтобы он бегал сам, открой скрипт и заполни в начале файла:
```js
HIVE_WALK: [],                          // от точки респавна до кнопки Make Honey
ROUTE_TO_FIELD: [[90, 4000], [0, 1500]] // [угол, миллисекунды]
```
Угол: **90 — вперёд, 0 — вправо, 180 — влево, 270 — назад** (относительно камеры). Подбирай время, пока персонаж не будет попадать в центр поля.

## Тонкая настройка (в начале скрипта, блок `CFG`)
- `COLOR_THRESHOLD` — насколько цвет может отличаться. Бот бежит к траве/пчёлам → уменьши. Не видит токены → увеличь.
- `MIN_TOKEN_CELLS` / `MAX_TOKEN_CELLS` — размер пятна, которое считается токеном.
- `IGNORE_TOP` / `IGNORE_BOTTOM` / `IGNORE_LEFT` / `IGNORE_RIGHT` — края экрана с интерфейсом, куда бот не смотрит.
- `FIELD_RADIUS` — размер поля (в секундах ходьбы от центра), `LEASH` — дальше этого за токенами не бегает.
- `JOY_RADIUS` — насколько оттягивать джойстик. Персонаж идёт медленно → увеличь.
- `AUTO_TAP` — тапать инструментом или нет.
- `STEP_MS` — как часто бот принимает новое решение (мс).

Бот нажимает, только когда на экране Roblox (`com.roblox.client`). Свернул игру — он ждёт.
