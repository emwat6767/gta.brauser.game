# Roblox Token Farm

Макрос сам бегает и собирает токены. Он смотрит на окно Roblox, находит токены по цвету,
бежит к ближайшему на WASD, а если токенов не видно — ходит змейкой и ищет.
В игру ничего не внедряется: только скриншоты и нажатия клавиш.

## Запуск (Windows)
1. Поставь Python 3 с python.org. При установке отметь галочку **Add Python to PATH**.
2. Скопируй папку `roblox-token-macro` себе на ПК и запусти `run.bat`
   (при первом запуске он сам поставит библиотеки).
3. Зайди в Roblox и **настрой камеру**: отдали её колесом и смотри на поле сверху вниз.
   Shift Lock выключи. Чем ровнее камера смотрит сверху, тем точнее макрос бежит к токену.

## Настройка (один раз)
| Клавиша | Что делает |
|---|---|
| **F8** | наведи курсор на токен и нажми — макрос запомнит его цвет. Разные токены → жми F8 на каждом |
| **F7** | сбросить все цвета |
| **F9** | наведи курсор на своего персонажа и нажми |
| **F10** | окно отладки: красным — что макрос считает токеном, зелёные кружки — цели |
| **F6** | старт / пауза |
| **F5** | перечитать `config.json` после правки |
| **End** | выход |

Макрос нажимает клавиши, только когда активно окно Roblox. Переключился в другое окно —
он отпускает клавиши и ждёт. Аварийная остановка: увести мышь в левый верхний угол экрана.

Окно отладки (F10) при открытии забирает фокус — просто кликни обратно в Roblox.

## Тонкая настройка `config.json`
Все пиксели считаются на кадре шириной 640.

- `hsv_tolerance` `[оттенок, насыщенность, яркость]` — насколько цвет может отличаться.
  Ловит траву/пчёл/лишнее → уменьши. Не видит токены → увеличь.
- `min_blob_area` / `max_blob_area` — размер пятна, которое считается токеном.
- `ignore_top` / `ignore_bottom` — доля экрана сверху/снизу (интерфейс), которую не смотреть.
- `ignore_radius` — круг вокруг персонажа, который не смотреть (если персонаж сам похож на токен).
- `patrol` — маршрут поиска, когда токенов нет: `["клавиша", секунды]`, можно `"w+d"`.
  Пустой список `[]` — стоять на месте.
- `auto_click` — `true`, чтобы ещё и кликать ЛКМ (например, собирать пыльцу инструментом).
- `target_timeout` — если за столько секунд не приблизился к цели, она временно игнорируется и персонаж прыгает.
- `window_title` — заголовок окна игры (обычно `Roblox`).
